# Accessibility

This page records GWO's audit against WCAG 2.2 at Level AAA, and the rules that
keep new markup in line with it.

## Scope

The audit covers only the markup GWO owns: the files under
`ui/mods/com.pa.quitch.gwaioverhaul/`, including the stock panels GWO replaces
outright (`#hover-card`, `#system-card`, the tech-card options bar, and the
planet list). Stock UI around it is out of scope, even where GWO's controls use
stock classes.

One group of criteria is out of scope, because the engine cannot support it:

- **Programmatic semantics.** PA passes no accessibility tree to Windows, so no
  screen reader can read PA. On both UI backends, Windows UI Automation finds
  none of the UI inside PA's window, only the window's own title bar and
  buttons (measured with no screen reader running). ARIA roles, accessible
  names, `alt` text, and status messages would reach no one.

Two things this audit once ruled out do work, on both UI backends. Both were
measured in November 2026:

- **Tab moves focus.** A real keyboard's Tab moves focus between inputs,
  buttons, and `tabindex` elements, and stock does not cancel it. An earlier
  measurement that found Tab did nothing on Coherent UI was wrong. The keyboard
  rows below are therefore assessed, and most are gaps, because Tab skips GWO's
  `div` controls.
- **The UI zooms to 200%.** Settings > GUI Size scales the whole UI like browser
  zoom: at 200% the page sees a device pixel ratio of 2. Stock's war setup and
  galaxy map set a minimum page size of 1280 × 720 CSS pixels
  (`html, body { min-width: 1280px; min-height: 720px }`), and stock's `body`
  hides overflow. At 200% a 1920 × 1080 window has a viewport of 952 × 521 CSS
  pixels, so the right and bottom of each scene are out of reach, GWO's panels
  included (1.4.4).

The keyboard rows were measured in war setup, with and without the AI modal
open, on both UI backends, and on the galaxy map on CEF. The zoom rows were
measured in war setup and on the galaxy map on CEF. Not yet checked for either:
the hover card, the system card, the tech-card options bar, the planet list, the
Commander and game options modals, the co-op slot list, the overlays, and the
battle scene.

## Rules for new markup

- **A tooltip trigger carries `gwo-tip`.** `shared/tooltips.js` then lets
  Escape dismiss the tooltip (1.4.13), and keeps it open while the pointer is
  over it. Bootstrap 3 would otherwise hide it as the pointer leaves the
  trigger, and stock sets `pointer-events: none` on every tooltip.
  `shared/tooltips.css` gives the tooltip a line height of 1.5 (1.4.8), lets a
  showing tooltip take the pointer, and gives an `info_tip` "?" a 24px target
  (2.5.8). A tooltip that would cover neighbouring targets the player sweeps
  across, as the planet icons' do, is left out of the pointer rule.
- **Text contrast is 7:1** against the worst background it can sit on (1.4.6).
  Where a panel is translucent, work out that worst case with a white galaxy
  behind it. That is why the war information panel is 95% opaque and its
  warnings are `#f99`.
- **A control's outline is 3:1** against its background (1.4.11).
- **A click target is 44 × 44px** (2.5.5). To reach that without changing a
  stock-styled control's look, give it a transparent `::before` hit area, and
  check that the area does not overlap the next target. A `::before` is placed
  from the padding edge, so an offset must include the control's border: a 30px
  switch with a 1px border needs `-8px` above and below, not `-7px`. Stock's
  switch rows sit on a 44px pitch, so that is as far as a switch can grow.
  Stock sets `box-sizing: border-box` globally, so padding added to reach 44px
  needs `content-box`. Measure a hit area by hit-testing points with
  `elementFromPoint`, not by adding the offsets to the element's size.
- **An action that cannot be undone asks first** (3.3.6). Delete Tech changes
  to "Delete this Tech?" on the first press, and deletes on the second.

## Results

Status values:

- **Pass**: meets the criterion as shipped.
- **Fixed**: met after this audit.
- **N/A**: GWO has no content of that kind.
- **Engine**: out of scope for the engine reason above.
- **Gap**: a known failure, with the reason it remains.
- **Open**: in scope, not yet measured.
